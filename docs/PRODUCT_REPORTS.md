# Relatórios do Projeto

Padrão organizacional para apresentar documentação de homologação dentro do produto sem expor dados sensíveis.

A área pública de homologação deve consumir apenas um relatório sanitizado e deliberadamente reduzido. Nenhuma credencial, dado pessoal, log bruto, arquivo `.env`, token, senha, secret, API key ou connection string pode ser publicado.

O relatório deve facilitar revisão, comparação entre planejado e entregue, cópia de contexto para conversas e registro de novas ideias.
