# Produtos em Homologação

## Objetivo

Disponibilizar no site A-Castilho uma área pública para que clientes e visitantes possam visualizar e acessar os produtos que estão atualmente em ambiente de homologação.

## Navegação

O menu principal do site deverá possuir uma opção dedicada, com o nome **Produtos em Homologação**.

Ao selecionar essa opção, o visitante será direcionado para uma página própria com os produtos liberados para visualização em homologação.

## Página de Produtos em Homologação

A página deverá apresentar os produtos em formato de cards.

Cada card deverá conter:

- nome do produto;
- descrição curta;
- status **Em homologação**;
- data da última atualização, quando disponível;
- botão **Acessar homologação**;
- link para o ambiente público de homologação do respectivo produto.

## Regras de Exposição

- Somente produtos explicitamente marcados como visíveis para clientes deverão aparecer na página.
- Projetos internos, ambientes de desenvolvimento e produtos ainda não liberados para avaliação externa não deverão ser exibidos.
- Um produto deverá deixar de aparecer automaticamente na área de homologação quando seu status público for alterado.
- O acesso à página não deverá exigir autenticação, salvo se um produto específico possuir sua própria regra de acesso.

## Experiência do Usuário

A página deverá seguir a identidade visual do site A-Castilho e funcionar adequadamente em desktop e dispositivos móveis.

O status de homologação deverá ser visualmente claro para evitar que o visitante confunda o ambiente de testes com uma versão definitiva do produto.

## Escopo desta especificação

Este documento define apenas o requisito funcional da área **Produtos em Homologação**. A implementação técnica será tratada separadamente.
